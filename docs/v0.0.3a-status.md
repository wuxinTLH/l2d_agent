# v0.0.3a 发布状态

## 已验收能力

- PSD 增加标准 ResolutionInfo 图像资源，修复 Cubism 5.3.05 实际读取空文档问题；原生读取器及 GUI 样例验证尺寸、位置和遮挡。
- 项目内 dsh-cubism 插件，包含本地工作室 HTTP 工具与官方六方法文档/参数 API。
- 固定样例的自动网格、单眼关键形，以及分层左右眼独立开闭、嘴部和舌头关键形。已在 Cubism 5.3.05 FREE 保存并重开验证。
- 桌面操作有前台/进程/固定文档/窗口尺寸检查、互斥锁及输出范围校验。不是任意角色通用建模器。

## 保留的未完成目标

上下眼睑和上下唇沿曲线向共同中线汇合，眼角/嘴角尽量固定；眼球和口腔保持分层。在 Cubism FREE 保存重开验证全开、半开、闭合。

此目标尚未完成。当前已发布的 face recipe 仍使用覆盖层平移，不能视作曲面形变。局部顶点拖动试验曾出现折线尖角，已尝试撤销，未作为验收模型发布。下一步需要可靠的逐顶点选择、平滑变形场、固定端点和中线误差验证。

本次仅发布受审查的代码和说明；`.local/` 中的模型、截图、试验脚本、用户素材及 Cubism 软件本体不上传。历史验收报告含本机路径，它们不是仓库自带下载文件。
